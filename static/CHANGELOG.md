# 2.0.0

## Новые функции

- Полный перенос кодовой базы на Svelte 5 с использованием рун (`$state`, `$derived`, `$effect`)
- Переработка глобального состояния на базе реактивных классов Svelte 5
- Внедрение ленивой загрузки Monaco Editor через `@monaco-editor/loader` без необходимости встраивания веб-воркеров
- Добавлены режимы **Chat** (Чат) и **Result** (Результат) для тонкой настройки вывода
- Реализована блокировка и скрытие списков (`[LIST]`), таблиц (`[TABLE]`) и спойлеров (`[SPOILER]`) в режиме **Chat**
- Добавлена опция отключения разделительной линии (`[HR]`) с автоматическим отключением в режиме **Chat**
- Настроены пайплайны CI/CD для GitHub Actions (тестирование в `CI.yml` и деплой на GitHub Pages в `deploy.yml`)
